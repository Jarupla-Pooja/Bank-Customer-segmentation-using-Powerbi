
# Bank Customer Segmentation Dashboard – Power BI

This project focuses on analyzing and segmenting bank customers using **Microsoft Power BI** to understand customer demographics, behavior, and financial patterns. The dashboard transforms raw customer data into meaningful visual insights that help identify different customer segments and support data-driven decision-making.

### Project Objectives
- Analyze customer demographics such as age, gender, and location.
- Understand customer distribution across different segments.
- Identify patterns and trends in customer data.
- Build interactive dashboards for exploring customer information.
- Present key insights through clear and meaningful visualizations.

### Tools & Technologies
- **Power BI** – Dashboard development and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures and analysis
- **Data Modeling** – Organizing data for effective reporting

### Key Features
- Interactive dashboard with slicers and filters.
- Customer demographic analysis.
- Visual representation of customer segments.
- KPI cards, charts, and navigation buttons.
- Clean and user-friendly dashboard design.

### Key Learning Outcomes
This project helped me improve my practical skills in Power BI, data cleaning, data visualization, and analytical thinking. It also provided hands-on experience in transforming raw data into interactive dashboards and extracting useful insights to support business decisions.
